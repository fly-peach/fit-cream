## 任务二：优化 ExerciseService 并集成前端

### 现状

| 维度 | 现状 |
|------|------|
| 后端 Service | 只读，6 个查询方法，无 CRUD |
| 后端 Model | exercises 表 7 个字段，muscle_group/equipment/difficulty 已加索引 |
| 后端 Schema | 无独立文件，ExerciseOut 内联在 router，ExerciseBrief 在 schemas/plan.py |
| 后端 Router | 仅 2 个 GET 端点（列表 + 详情），无管理端 CRUD |
| 后端 Seed | 无动作库种子数据 |
| Agent Tools | 2 个工具使用：exercise_tools 搜索 + checkin_tools 名称匹配 |
| 前端页面 | 无独立页面，仅在 plans.tsx 中作为搜索选择器出现 |
| 前端导航 | 无入口 |

### 目标

将 ExerciseService 从只读查询服务升级为**完整的动作库管理服务**，并在前端新增独立页面，用户可浏览、搜索、筛选动作库。

### 后端改造

#### 2.1 Exercise 模型增强

| 新增字段 | 类型 | 说明 |
|----------|------|------|
| `category` | String(50), nullable, 索引 | 动作分类：compound(复合) / isolation(孤立) / cardio(有氧) / mobility(灵活性) |
| `is_compound` | Boolean, default=False | 是否复合动作（便捷过滤） |
| `muscle_subgroup` | String(50), nullable | 细分肌群，如 chest 下分 upper_chest / middle_chest / lower_chest |
| `calories_per_min` | Numeric(6,1), nullable | 每分钟消耗热量估算(kcal)，用于有氧动作 |
| `instructions` | Text, nullable | 动作执行步骤（分步骤说明） |
| `tips` | Text, nullable | 注意事项 / 常见错误 |

#### 2.2 ExerciseService 新增方法

| 方法 | 功能 | 权限 |
|------|------|------|
| `create_exercise` | 创建动作 | admin |
| `update_exercise` | 部分更新动作（exclude_unset） | admin |
| `delete_exercise` | 删除动作（校验是否被计划/打卡引用） | admin |
| `count` | 动作总数（支持与 search 相同的过滤条件） | user |
| `list_categories` | 返回所有分类 + 各分类动作数 | user |
| `list_muscle_groups` | 返回所有肌群 + 各肌群动作数 | user |

#### 2.3 独立 Schema 文件

创建 `rogers/src/fitme/schemas/exercise.py`，从 router 和 plan.py 提取：

| Schema | 用途 |
|-------|------|
| `ExerciseCreate` | 创建请求 |
| `ExerciseUpdate` | 部分更新请求 |
| `ExerciseOut` | 完整输出（含所有字段） |
| `ExerciseBrief` | 摘要输出（嵌入计划/打卡场景） |

将 `schemas/plan.py` 中的 `ExerciseBrief` 改为从此文件 re-export，保持向后兼容。

#### 2.4 Router 增强

| 端点 | 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|------|
| 列表 | GET | /api/exercises | user | 现有，增加 category 过滤 + 返回总数 |
| 详情 | GET | /api/exercises/{id} | user | 现有 |
| 分类统计 | GET | /api/exercises/categories | user | 新增 |
| 肌群统计 | GET | /api/exercises/muscle-groups | user | 新增 |
| 创建 | POST | /api/exercises | admin | 新增 |
| 更新 | PUT | /api/exercises/{id} | admin | 新增 |
| 删除 | DELETE | /api/exercises/{id} | admin | 新增 |

#### 2.5 种子数据

创建动作库种子脚本，预置 30-50 个常见健身动作，覆盖各肌群和器械类型。放在 `rogers/src/fitme/services/seed_service.py` 或独立 seed 脚本。

### 前端改造

#### 2.6 动作库页面

新增 `frontend/src/pages/exercises.tsx`，功能：

- 顶部搜索栏：关键词搜索
- 筛选器：肌群 / 器械 / 难度 / 分类（下拉或标签）
- 动作卡片列表：展示名称、肌群标签、器械标签、难度、简述
- 点击卡片展开详情：执行步骤、注意事项、热量消耗
- 分页加载（使用 offset 参数）

#### 2.7 导航集成

在 `frontend/src/components/app-layout.tsx` 的 `useNavItems()` 中新增：

```
{ to: "/exercises", label: "动作库", icon: DumbbellIcon }
```

插入位置：训练计划之后，知识库之前。

#### 2.8 路由注册

在 `frontend/src/App.tsx` 中新增：

```
<Route path="/exercises" element={<ProtectedRoute><ExercisesPage /></ProtectedRoute>} />
```

#### 2.9 类型定义

在 `frontend/src/types/` 中新增 `exercise.ts`，定义前端 TS 接口，替换 plans.tsx 中的内联 ExerciseBrief。
